## Task and Constraints

需要区分三层结论：VID005 与 CS500 套件互配、VID005 与 ZCU104 FMC 电气/管脚兼容、以及是否存在可在 Vivado 2022.2/PYNQ 上重建的完整 CSI-2/传感器初始化/ISP 软件工程。不得以同一商品套餐或其他 FPGA 平台演示替代 ZCU104 实证。

## Contributions

- 检查米联客 VID005 官方产品图片：确认一组 4-lane CSI 输入、一组 4-lane DSI 输出、FMC LPC 连接；J2 CSI/J3 DSI 表中控制 IO 标称 1.8 V，CSI 连接器另供 3.3 V。
- 识别 CAM001-CS500 商品说明为 5MP、CSI 2-lane；公开资料没有给出该模组在 ZCU104 上的 lane rate、寄存器表或 RAW/Bayer 配置。
- 从 VID005 公布的连接图提取 CSI HS pinout：clock=`FMC CLK0_M2C`，D0=`LA00`，D1=`LA03`，D2=`LA04`，D3=`LA08`；对应 ZCU104 package pins 为 E15/E14、F17/F16、K19/K18、L17/L16、E18/E17，均位于 Bank 67。
- 用 Vivado 2022.2 对 `xczu7ev-ffvc1156-2-e` 创建 MIPI D-PHY 4.3 RX 探针配置。IP 配置器拒绝 E15 作为 RX clock lane，并拒绝 VID005 的数据 lane 组合，证明其公开 pinout 不能直接使用 AMD UltraScale+ 原生 MIPI D-PHY。
- 确认本机 `mipi_csi2_rx_subsystem 5.2`、`mipi_dphy 4.3` 等 MIPI IP 的 `REQUIRES_LICENSE=0`；当前主要障碍不是授权，而是 PHY/pinout 和板级软件资料。
- 区分“硬件理论可通过自定义软 D-PHY 使用”与“有现成 ZCU104 软件栈”：VID005 把 HS/LP 分开引出，可能适配厂商自研 PHY，但当前公开演示是米联客/安路平台，产品图示例为 L2_CZ06_DR1M90G+IMX415，不构成 ZCU104+CS500 实证。

## Decisions and Adoption

形成并接受 D-022 工程评估：不批准该组合为即插即用或低风险采购；只有卖方提供 ZCU104/Vivado 2022.2 完整可综合 PHY/CSI/XDC/CS500 初始化及板测证据时才重新评估。当前项目维持 OV5640 DVP 路线。

## Commands and Tools

读取项目上下文；检索并查看米联客官方 VID005 产品页及产品图片；检索 AMD MIPI D-PHY/CSI-2 官方资料；运行 Vivado 2022.2 Tcl 查询 ZCU104 管脚 Bank/功能、MIPI IP 授权元数据，并尝试生成 VID005 原生 D-PHY pin 配置。

## Validation and Evidence

- `query_zcu104_fmc_mipi_pins.tcl`：确认上述 CSI HS pins 均在 Bank 67；E15 为 `IO_L12P_T1U_N10_GC_67`，F17 为 QBC pin，但 VID005 固定将前者接 clock、后者接 D0。
- `validate_vid005_native_dphy.tcl`：Vivado 报 `E15` 超出 Clock Lane LOC 合法范围；同时 K19/L17/F17/E18 不满足所选 4-lane RX 数据位置组合，`set_property` 失败。该失败是本次结论的关键可复现实证。
- `query_vivado_mipi_ip.tcl`：MIPI CSI-2 RX Subsystem 5.2 和 MIPI D-PHY 4.3 均为 `REQUIRES_LICENSE=0`。
- AMD PG202 说明 UltraScale+ RX clock lane 必须使用所选 HP bank 的 DBC/QBC 资源，且 IP 由 pin planner约束合法组合；PG232 说明 UltraScale+ 使用 `MIPI_DPHY_DCI` 并由子核生成 LOC。
- 未执行：购买、物理接线、CS500 I2C 初始化、bitstream implementation、时序、ILA 或连续采集。不能宣称物理链路已验证。

## Errors and Corrections

最初依据套餐关系只能确认 VID005 与 CS500 连接器层面的互配，不能推导 ZCU104 可用。进一步进行 Vivado pin-planner 验证后发现原生 D-PHY pinout 冲突，故把先前“资料齐全即可优先 CS500”的宽泛建议收紧为必须获得厂商 ZCU104 专用软 PHY 工程，否则不采用 VID005。
