## Task and Constraints

## Contributions

- Defined the recommended PL-first data path: PS I2C configuration of IMX219 → J9 two-lane MIPI D-PHY RX → CSI-2 RX → RAW10 AXI4-Stream → Bayer-to-GRAY8 ISP → threshold/enhancement → binary GRAY8-to-RGB888 → DDR frame buffer/VDMA clock-domain bridge → HDMI transmitter.
- Identified an interface adaptation requirement: the existing threshold demonstration treats a full frame as one DMA packet with EOF TLAST, whereas conventional AXI4-Stream Video uses SOF in TUSER and EOL in TLAST. The production CSI path should upgrade/wrap the threshold core for AXI4-Stream Video semantics rather than concatenate a live frame into a simple-DMA packet.
- Clarified that IMX219 outputs Bayer RAW, not GRAY8. A Bayer-aware line-buffered gray/ISP stage is required before thresholding; selecting only a fixed mosaic color plane is not an acceptable full-resolution whiteboard path.

## Decisions and Adoption

- Applies D-035: CSI-2 raw-pixel capture is the preferred stable 1080p30 final route; UVC MJPEG remains the fallback.
- Use a PS-controlled/PL-streaming split: PS configures sensor and display controls only; it must not receive, decode, or copy video frames in the normal CSI route.
