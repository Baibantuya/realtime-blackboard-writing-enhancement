# 物体漏检与 ONNX 一致性分析

2026-10-17，Asia/Shanghai。单代理完成，结果来自服务器原件及本轮实际诊断。原模型问题尚未修复；本轮完成错误归因和数值定位。

## 1. 结论与证据范围

物体漏检主要包含定位/框范围问题和低分候选，小目标尤其困难，但不能把全部漏检都归因于小目标。NMS 和类别竞争在当前阈值下对应的数量较少，暂不优先调整 NMS 或更换解码类别规则。

ONNX 严格超差定位到未进入候选集合的单位方向分量。归一化前原始方向范数很小时，约 10⁻⁶ 量级的后端差异被放大为约 10⁻³ 量级的单位方向差异。中间张量探针支持这一传播机制；最初数值漂移尚未归因到唯一算子。

51 张固定样本上的检测候选/NMS 保留项、持物判定和配对没有改变，但原始严格张量判据仍失败。不能把本报告写成标准 validate 已通过，也不能外推为整个验证集、真实域或板端等价。

本轮未移动或删除文件，未修改正式模型、训练源码、数据划分、原日志或原失败报告。只新增独立工具、诊断输出和本报告。未进行新训练、量化或最终测试集评分。

## 4. 物体漏检分解

以下是明确优先级规则下的候选阶段分组，总和为 1196。它们是可复核线索，不是已经人工证实的互斥视觉根因。

| 主分组 | 数量 | 占 FN |
| --- | ---: | ---: |
| 候选框定位或范围不足 | 512 | 42.81% |
| 存在可匹配候选，但分数低于 0.5 | 450 | 37.63% |
| 0.01 候选中缺少接近 GT 的物体框 | 190 | 15.89% |
| 高分候选被 NMS 抑制 | 20 | 1.67% |
| 手/物体类别竞争的反事实线索 | 16 | 1.34% |
| 贪心匹配竞争 | 8 | 0.67% |

“定位或范围不足”指 0.01 后 NMS 的物体候选中存在 IoU≥0.1，但没有可用 IoU≥0.5 匹配。它可能包含模型定位、物体可见范围、原 GT 框语义或候选抑制等影响，不能只凭统计认定标注错误。

“NMS 抑制”仅计入原本得分≥0.5 且能覆盖 GT 的候选被抑制的情况。低分候选间的抑制可能落入其他主分组，因此 20 不是所有形式 NMS 影响的上限。“类别竞争”是保留同位置物体类别分数的反事实线索，不证明该候选真实语义就是物体。

大目标也不能忽略：短边在 416 尺度大于 32 像素的目标仍有 702 个 FN，占全部 FN 的 58.70%。应先审阅其中的定位/GT 语义问题，再决定是否增加输入尺度。

## 6. 降低物体阈值的实际收益与代价

手与持物阈值始终固定 0.5。下表只是验证集探索，没有修改部署默认值。

| 物体阈值 | 预测数 | TP | 物体 precision | 物体 recall | 全关系 recall | 预测关系 precision |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 0.5 | 935 | 633 | 67.70% | 34.61% | 33.41% | 54.92% |
| 0.3 | 1376 | 756 | 54.94% | 41.33% | 37.41% | 46.47% |
| 0.1 | 2335 | 909 | 38.93% | 49.70% | 39.00% | 39.17% |
| 0.05 | 3137 | 981 | 31.27% | 53.64% | 38.69% | 36.29% |

阈值 0.3 相比 0.5 多恢复 123 个物体 TP、91 条正确关系，但物体 FP 从 302 增加到 620，预测关系 precision 下降。0.1 恢复更多目标，但 FP 为 1426，不能只依据 recall 选择它。

在 1412 个源视频上做配对分组 bootstrap（2000 次，seed=20261017），0.3 相比 0.5 的全关系 recall 增益 95% 区间为 +3.01～+4.97 个百分点；0.1 的区间为 +4.27～+6.99 个百分点。区间针对当前公开验证数据，视频分组不保证人物独立，也不证明真实域泛化。

## 7. 关系链路及关联规则

对全部 2272 条有效 GT 关系采用互斥顺序，计数完全闭合：

| 阶段 | 数量 | 占全部关系 |
| --- | ---: | ---: |
| 手未检出 | 417 | 18.35% |
| 手检出但对应物体未检出 | 1037 | 45.64% |
| 手物均检出但持物门控拒绝 | 42 | 1.85% |
| 候选及门控通过但配错 | 17 | 0.75% |
| 最终正确 | 759 | 33.41% |

手与对应物体均检出的候选上限为 818/2272=36.00%，最终正确为 759/2272=33.41%。在 818 条候选齐全的关系中，42 条被持物门控拒绝，17 条配错；当前优先解决候选检出和定位比先改关联规则更有依据。

同候选、同门控比较：物体阈值 0.5 时向量/几何分别正确 759/767；0.3 时为 850/847；0.1 时为 886/877。默认阈值下向量比几何低 0.35 个百分点，源视频分组 bootstrap 95% 区间约为 -0.66～-0.09 个百分点；低阈值下两者差异区间包含 0。多物体子集在这三个阈值下向量仍未超过几何，不宜宣称已取得稳定关联优势。

持物阈值由 0.5 提高到 0.6，可将匹配手上的 FPR 从 68.04% 降到 33.76%，但持物 recall 从 88.66% 降到 68.32%，全关系 recall 从 33.41% 降到 29.27%。单纯提高持物阈值存在明确漏检代价。

## 9. 数值放大的定位证据

归一化前方向为 `(dx_raw, dy_raw)`，范数 r 很小时，单位方向对输入微扰的敏感度约随 1/r 增大。这里 r 不是物体距离预测 `length_px`。

OpenCV 超差元素处 r 的中位数约 0.00305，单位方向差异相对原始分量差异的放大倍数中位数约 262.5、最大约 1587.8；ORT 对应约 270.2 和 1581.8。原始分量微扰经一阶切向近似解释后的误差，在本轮最差约为 0.70%，支持该传播机制。

原图 2 的候选 2068：PyTorch/OpenCV 的 unit_dx 为 0.04504085/0.04610368，差 0.00106283，边界为 0.00104610；候选分数约 3.03×10⁻⁸。原始方向分量差异范数约 5.85×10⁻⁶，经归一化后方向差异约 0.001064。

原图 20000 的候选 2168：PyTorch/OpenCV/ORT 的 unit_dy 为 -0.15790628/-0.15610752/-0.15664977；候选分数约 5.26×10⁻⁸。

原始关系 Conv 中间输出在内存中探测，没有导出或覆盖 ONNX。28 次探针的最终输出与原会话输出逐值相同，排除了本次增加探针改变最终计算结果的影响。额外 CPU Float64 参考下，上述两个原失败分量中 OpenCV/ORT 比 PyTorch Float32 更接近参考值；这说明不能把全部差异简单归为后端算错。Float64 参考只用于诊断，没有替换正式 Float32 模型。

已定位的是方向归一化的误差放大机制。其输入微小漂移来自不同执行路径，尚未逐层定位到唯一卷积、融合或其他算子。

## 11. 下一步的最小实验与审阅顺序

1. 先审阅固定清单中的定位/范围不足、低分、大 GT 框及微小目标。当前已有 200 张唯一图像的审阅清单，尚未人工确认遮挡、物体类别或 GT 正确性；原 GT 保持不变。
2. 把阈值 0.5/0.3 作为真实握笔开发集上的独立推理对照，同时检查新增误检和遮挡覆盖。当前公开验证结果不足以直接改部署默认值。
3. 输入尺度或受限 crop 先选一个因素研究。512 只是使线性尺度增加约 23.1%，8 像素约变 9.85 像素，并不保证解决微小目标；像素数增加约 51.5%，必须计入 PS 实测成本。输入、向量长度、网格输出、导出和解码契约要配套验证。
4. 对定位与低分问题，在标注审阅后再选采样、数据或损失的单因素训练实验。使用同初始化、同日程控制组；不以延长当前任务替代消融。
5. ONNX 后续保留原失败证据，扩大阈值/NMS/配对边界覆盖，再审阅数值稳定化方案或语义分层验收提案。任何新判据都要保留原判据结果；本轮严格门禁状态仍为失败，不删除断言、失败样本或直接放宽容差。
