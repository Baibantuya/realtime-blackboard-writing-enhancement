# Linux 显示与输入

2026-10-18：已新增 SDL2 后端 `preview_sdl.c`，可在本机 WSL2 的 Ubuntu 22.04.5 / WSLg 中运行现有 LVGL 界面。当前是合成画面的交互入口，尚未接入相机、真实增强像素、历史帧或 KV260 DRM/DP。

## 打开界面

本机已经完成构建。在 Windows PowerShell 输入：

```powershell
wsl -d Ubuntu-22.04 --exec /home/ubuntu/board-system/ui-linux-20261018/build/board_light_preview_linux
```

也可以使用本目录的 `Launch-LinuxUI.ps1`。它从发行版默认普通账户读取主目录，不需要管理员权限；遇到 PowerShell 脚本策略限制时，仅对本次启动使用：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\2026嵌赛\实时板书增强系统\ui\lvgl\Launch-LinuxUI.ps1"
```

关闭窗口即可退出。程序只打开自己的 SDL 窗口；“模拟断开／返回演示”只切换本地状态。画面的线条是对比度示例，切换增强模式、记录板面和恢复开关只验证控件与状态，不生成真实处理结果。

## 显示、字体与文案

- 沿用暖灰、粉紫布局：1920×1080 合成画面，底部 1920×320 叠层，坐标原点位于 y=760。窗口默认原生 1920×1080，最小 960×540；缩放保持比例，其他区域留黑边。1920×320 是 UI 占据的覆盖区域，每个像素直接对应 1080p 画面中的一个像素，不是把 320 行拉伸成整屏。
- 默认收起操作栏和状态条，只在右下角保留上箭头。点击上箭头展开；同一位置变为下箭头，点击即可收起。收起时不保留文字摘要；弹窗显示期间隐藏箭头，取消后回到原来的展开状态。箭头使用矢量线条，避免依赖符号字体。
- 展开后 10 秒无操作自动收起。点击、键盘输入及操作栏区域内的鼠标移动重新计时；鼠标按住、确认框、参数页、诊断页和等待设备回执期间暂停自动收起。关闭弹窗后重新给予完整 10 秒。只隐藏界面，不改变模式、板面、记录或恢复开关；视频、诊断和状态更新不会延长计时。
- 历史恢复开启按钮使用暖棕色 `#8B6048`。记录弹窗说明改为“记录完成后，可手动开启历史恢复”；记录本身不会自动打开恢复开关。
- SDL2 软件渲染器提交 ARGB8888 画面，在原生 1080p 下逐像素输出；缩小或放大窗口时使用明确设置并检查过的线性采样，避免默认最近邻采样造成的跳变、锯齿和细笔画丢失。显示和鼠标坐标分别按绘制输出尺寸、窗口逻辑尺寸计算，以兼容窗口缩放与高 DPI；黑边和板面区域不会误触底栏。Windows 预览设置 DPI 感知，并将客户区而非包含边框的外窗设为 1920×1080。
- 已按用户要求恢复 Noto Sans SC Regular（字重 400），保留 20／24／28 px 三档，字形改为 8 bpp（256 级灰度覆盖率）。三档字形位图合计 497075 字节，比上一版 Medium / 4 bpp 增加 245491 字节，约 240 KiB；字号、字宽和画布保持原设计。运行时不依赖 Windows 字体路径、系统中文字体或 Pillow。字体源 SHA256：`763146584cf0710223441356b4395e279021b0806c196614377a7a0174ae074a`；许可证见 `fonts/OFL.txt`。
- 本轮字形子集为 358 个字符。界面自检逐个检查可见标签的字形与宽度；Windows 和 Linux 共用同一字体与视图实现。
- 旧版默认 1440×810 将 20 px 小字缩到约 15 px；新版默认不再做这次 75% 缩小。1080p 是原生清晰度基准：原生输出自检回读整幅 1920×1080 像素，逐字节与合成结果比较，确认没有二次缩放。8 bpp 改善边缘覆盖率精度，不把 20 px 字形变成更高分辨率的字体；任意缩小窗口仍会损失细节，在 4K 屏幕上放大全屏也不等同于 4K 字体重绘。
- 精简来源、恢复状态和重复提示，例如“当前画面未使用历史板书”改为“未使用历史板书”；记录板面弹窗保留无遮挡、保留板书及恢复默认关闭的必要说明。
- “参数（演示）”明确保留旧参数的演示属性，不冒充新硬件的参数映射；原图与历史恢复仍是独立设置。禁用按钮保留可读的文字，焦点与选中状态使用不同外框。

## 操作

| 操作 | 方式 |
| --- | --- |
| 原图／初步增强／深度增强 | 鼠标，或 F1／F2／F3 |
| 黑白板切换、恢复、记录板面 | 鼠标，或 F4／F5／F6 |
| 参数、模拟断开 | 鼠标，或 F7／F8 |
| 呼出／收起操作栏 | 右下角上／下箭头，或 F9；收起时也支持 Tab 后回车 |
| 诊断页 | F10；记录确认弹窗中不响应 |
| 全屏、退出全屏 | F11、Esc；有弹窗时 Esc 优先取消弹窗 |
| 焦点、激活 | Tab／Shift+Tab、回车／空格 |
| 参数草稿 | 上下调整数值，左右选择位数；“应用参数”才生效，Esc 放弃 |

弹窗会拦截底层快捷键；诊断页返回参数页时保留草稿。失去焦点或拖出叠层时清理按下状态，避免产生意外点击。快速按下和释放分别交给 LVGL，不等待下一轮定时器。

自动收起实现在共用视图中，使用 LVGL 显示的活动时间和 250 ms 检查定时器，超时常量为 `LO_AUTOHIDE_MS=10000`。绕过 LVGL 输入设备的后端按键／鼠标事件应调用 `lo_view_activity()`；不要在画面刷新或状态回读时调用。Windows 窗口使用实际单调时钟差值推进 LVGL，与 Linux 的计时语义保持一致。

## 构建与复现

需要 C/C++ 工具链、CMake、Ninja、pkg-config、SDL2 ≥2.0.18，以及固定的 LVGL 9.6.0 源码。本机使用 GCC 11.4、SDL2 2.0.20；LVGL 压缩包保存在 `D:\WSL\Downloads\lvgl-9.6.0-80ca777e.zip`，SHA256 为 `3ddbd2ac5c98fbad41b7d0aa8f6026f722f5a11daaf32d0422da913ec44437da`。

在本机 Ubuntu 终端复现构建与四项 CTest：

```bash
python3 '/mnt/d/2026嵌赛/实时板书增强系统/ui/lvgl/tools/verify_linux.py' \
  --lvgl-archive /mnt/d/WSL/Downloads/lvgl-9.6.0-80ca777e.zip \
  --work "$HOME/board-system/ui-linux-20261018"
```

脚本校验压缩包及解压缓存的实际文件，将 UI 复制到 Linux 自有目录后构建；不会在 Windows 原工程生成编译产物。可在 CMake 中设置 `LO_BUILD_LINUX_PREVIEW=OFF`，只构建平台无关的 UI 库和控制测试。

Windows 和 Linux 均将 LVGL 的内存池设为有界的 512 KiB。最初 Linux 使用默认 64 KiB 时，在样式过渡分配处触发断言；加入自动收起的重绘检查后，Windows 的默认 64 KiB 也在圆角蒙版临时分配处失败，GDB 定位到 `circ_calc_aa4()` 的 `lv_malloc_zeroed()` 空返回断言，因此统一使用 512 KiB。两端自定义断言会打印文件和行号并退出，避免默认无限循环；实现位于沿用原文件名的 `linux_assert.h`。保留所有状态、回执和诊断校验，没有以关闭断言绕过问题。通过 LVGL 配置 `LV_THEME_DEFAULT_TRANSITION_TIME=0` 关闭主题颜色过渡，避免禁用瞬间文字与底色对比度不足；没有向该版本不检查空指针的过渡描述符传 NULL。内存池峰值记录只计算 LVGL 池，不包含视频与叠层缓冲。

真实窗口输入验证需要 xdotool 和本机已建的 Python 环境，输出目录应为新目录：

```bash
~/board-system/venvs/ui/bin/python -B \
  '/mnt/d/2026嵌赛/实时板书增强系统/ui/lvgl/tools/verify_x11_interaction.py' \
  --binary "$HOME/board-system/ui-linux-20261018/build/board_light_preview_linux" \
  --out "$HOME/board-system/ui-linux-20261018/evidence/my-window-check"
```

测试仅操作自己创建的窗口，每次按键前核对 X11 焦点；使用 XTest 事件，记录控件状态并回读 SDL 渲染器截图。该环境的 SDL 不接收 xdotool `--window` 生成的 XSendEvent 按键，因此最终输入验证使用 XTest。首次激活时，先等待 SDL 焦点稳定，再用不改变控制状态的修饰键确认事件实际送达；随后每项控制操作只发送一次。连续点击固定箭头时不使用会等待新鼠标位移的 `mousemove --sync`，而以实际控件状态检查点击结果。测试结束只关闭自己的进程。

开发用选项包括 `--size 1920x1080`（默认）、`--size 1440x810`（缩小预览）、`--state main|init|params|disconnected|collapsed|white|recovery|diagnostics`、`--capture new.bmp`、`--trace new.jsonl`。提供 `--capture-dir` 时，F12 保存实际渲染器回读；这些选项不出现在用户操作栏中。

## 验证记录与边界

证据目录：`evidence/member_c/light_overlay_linux_20261018/`。最终窗口记录以其中最终 `interaction_receipt.json` 和验证汇总为准；较早的 `x11_01` 等目录保留故障排查过程，不作为通过证据。

目前证明的是 x86_64 Linux 的界面显示、中文字形、鼠标键盘输入与软件状态约束。没有连接 KV260，没有修改算法、训练、RTL/HLS、固件或整机启动入口。SDL2 需要可用的 X11／Wayland 桌面服务；无桌面的板端 DRM/KMS、USB 输入设备权限和视频共显仍需实际板卡适配与验证。
