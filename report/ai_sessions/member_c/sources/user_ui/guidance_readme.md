# 相机移动提示页：字体与对齐

2026-10-18 更新。沿用 1920×1080、左侧 1440×810 原画面和右侧提示卡片，统一使用 Noto Sans SC Regular（思源黑体，400 字重）。右侧仅保留两级字号：动作标题 28 px，说明与后续动作 24 px。

所有方向和组合提示共用同一布局：方向图标、当前动作、两行简短说明，以及有后续步骤时的一行后续动作。删除重复的顶部引导语、“下一步”标签和底部附加说明，缩短分隔线，使内容集中在卡片中部。保留既有暖灰、暖白、淡紫和深色文字。圆内所有方向图标按中心等比缩小至上一版的 80%，线宽同步缩小；圆形底板直径保持 128 px。

居中按实际字形蒙版的可见边界计算，统一中轴 x=1696；不再依赖包含标点留白的字体排版框。旧版本三行说明的可见中心约左偏 7 px。行间步长 36 px（24 px 字号加 12 px 间距）。右上角标签按字形宽高加左右各 16 px、上下各 10 px 内边距生成，右边缘固定 x=1888，圆角 12 px。页眉和画面标签继续与左侧画面对齐。

`create_assets.py` 在开发端以 2 倍尺寸生成文字和矢量图形，再缩小到 1080p，输出与现有 PS 合成器兼容的 31 张 PNG 和哈希清单。生成时检查文字边界和内容栏宽度。运行时仍只使用 PNG／RGB565，不增加字体或 Pillow 依赖。字体许可沿用 [OFL.txt](../lvgl/fonts/OFL.txt)。

当前资源位于 `assets_20261018_v5/`；离线预览位于 `preview_20261018_v5/`，使用既有真实视频第 212 帧。上一版目录保留。预览中的方向是指定的版式状态，不是本轮新的检测结果。

复用现有候选包的 `BoardFrontend`，通过 `asset_dir` 显式指定新资源即可：

```python
renderer = BoardFrontend(asset_dir="/path/to/ui/camera_guidance/assets_20261018_v5")
```

原候选包、旧资源、冻结压缩包及其哈希清单保留。本轮提供视觉资源更新，尚未切换板端启动入口；不改变方向判断、四角检测、历史恢复或 LVGL 操作栏。
