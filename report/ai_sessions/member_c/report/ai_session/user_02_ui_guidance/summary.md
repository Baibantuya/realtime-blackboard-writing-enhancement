## 问题和输入

用户连续指出文字对齐不准确、右上角标签过大、文字过多且字号重心不均，以及圆内箭头过长。输入为既有相机引导布局、方向/旋转等状态和视频帧。这里检验排版，不评价识别算法。

## 协作过程（整理索引）

| 消息位置 | 用户反馈与AI修正 |
| --- | --- |
| U01–U05 | 先统一Regular字体，AI采用标题/箭头居中、多行说明块内左对齐；这不是用户最后接受的规则 |
| U06–U11 | 用户先要求三句话逐行居中，再要求动作标题也居中；AI产生v2/v3预览 |
| U12–U16 | 用户明确“仍然不是准确的居中”，并要求缩小标签与统一全体动作；AI发现排版框留白使可见字形偏移，改按字形可见边界计算 |
| U17–U19 | 用户认为箭头占比过大；AI将图标约缩小20%，所有方向按同一规则处理 |

不能把v1/v2/v3的“已居中”直接当作最终验收。可见用户反例是本案纠错证据；约7px偏差来自历史消息，v4最大0.5px来自已找回的validation。本轮未重新渲染测量每一行。v3的排版边界0偏差与v4的可见字形偏差采用不同口径，不能直接算改进率。

## 结果与边界

v5资源含28个引导状态和3个历史占位图，共31个；预览为28个引导页。最终记录为Regular、动作28px/说明24px、共同中轴x=1696，标签随文字包围盒加16/10边距、右边界1888，圆形直径128且内部图标缩为原来的80%。这些参数对应v5，不能和早期32px动作标题混写。

本轮补取v1–v4原预览、资源/预览manifest与validation，连同v5共核对295个资源/预览哈希。代表页可对照版式、标签和图标演变，见[五版图片与测量口径](version_history.md)。画面使用真实视频的指定帧与**人为指定的引导状态**；不能据它宣称相机方向判断正确。左侧像素不变是manifest的历史检查结果，本轮没有重新比较全部前版像素。
