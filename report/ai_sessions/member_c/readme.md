## 目录对照与使用边界

- report/ai_session/：拟用于报告协作章节的案例材料，正文引用包内相对路径。
- evidence/：已选取的日志、JSON、少量截图和验证脚本副本。
- sources/：赛题摘录、队友资料及工程说明副本；它们是证据来源，不是历史对话。
- skill/：可复用流程草稿，未安装到全局技能目录。
- tools/ 与根目录各 inventory/check JSON：本次整理工具、来源映射及只读核对记录；工具不是竞赛工程的运行入口。
- sources/、历史原文和部分原始回执中保留了旧机器路径、旧外链及过时状态；这些内容用于溯源，不应直接作为离线复现入口。正式提交需做独立副本、链接归一和匿名审查，不能覆盖历史原件。

本工作区位于中文路径下，不能直接当作满足官方命名规则的最终仓库。包内新文件采用英文名称；正式移交时需另设合规根目录，并保留来源映射。README.md/SKILL.md 为既定说明文件名；官方示例也使用 README.md。
