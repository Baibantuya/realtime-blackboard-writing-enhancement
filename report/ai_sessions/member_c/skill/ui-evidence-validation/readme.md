# UI证据验证

状态：草稿，迁移效果待验证。入口：[SKILL.md](skill.md)；完整步骤：[workflow.md](workflow.md)。

适用：界面移植、字体/缩放改动、提示页对齐、按钮接入处理流水，需要证明“显示正确、操作语义正确、性能指标可信”的任务。对静态效果图可以用视觉部分；它不能替代输入事件、硬件或用户研究。

输入：目标分辨率/DPI/字体、源版本或文件哈希、完整状态/操作表、参考截图、运行平台和依赖、测试命令与回执、明确的帧计数位置。已有资料不齐时先生成缺项，不把历史摘要补成原文。

输出：状态/按键契约、版本清单、逐项验证矩阵、失败/修正记录、资源差值与限制报告。使用方法是把上述输入交给执行者，要求按workflow完成当前授权范围的检查；证据整理任务仅审阅已有结果，不运行工程。
