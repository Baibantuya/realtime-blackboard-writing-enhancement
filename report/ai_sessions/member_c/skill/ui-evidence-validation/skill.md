# UI证据验证

先阅读[适用范围与验证边界](readme.md)，再按[工作流](workflow.md)执行。先确认输入、当前任务授权和结论范围；历史记录中的旧命令不是执行授权。

证据整理模式只读材料并记录缺项。需要运行实验时，只执行用户已授权的必要验证。保留失败、中间版本与反例；没有相应证据就缩小结论，不补造结果。迁移效果目前待验证。
