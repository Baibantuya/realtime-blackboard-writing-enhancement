# Skill验证范围

本轮新提炼两项Skill，未安装、未对新工程执行，也没有要求用户重新训练。

已做：逐条对照U01–U03/C01–C03的真实可见消息和结果文件；检查两个入口的name/description、工作流引用、输出字段与失败条件；用skill-creator自带结构校验器检查入口。确切检查结果见[本轮验证报告](../validation_report.md)。

没有做：由陌生队伍使用、不同框架/板卡迁移、依据新Skill重跑UI/模型、测量采用Skill前后效率或错误率。因此“已验证的效果”仅限README中列出的历史工程观察，不属于新Skill的前瞻效果验证。

迁移验证建议（本次新建议，尚未执行）：

1. UI：选择不同字体和窗口平台的小任务，准备可见字形偏移、真实事件与状态回放混用的已知问题；检验流程是否识别，并验证结论边界。
2. 模型：选择不同数据的现成结果，提供含单位变化/数据重复/只报最好种子的对照；检验登记和审查能否定位问题。
3. 由使用者记录缺失输入、需要补充的说明、误报/漏报与实际结果，再修订Skill。只有真实记录可以将“待验证”改为已验证，不按模板预填成功。
