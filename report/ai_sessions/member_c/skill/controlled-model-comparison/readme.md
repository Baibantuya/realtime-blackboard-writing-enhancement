# 受控模型比较

状态：草稿，迁移效果待验证。入口：[SKILL.md](skill.md)；步骤：[workflow.md](workflow.md)。

适用：检测或分类模型的导出诊断、输入尺度/阈值/数据路线、成对预处理与多种子小幅收益比较。它帮助确定能作何结论，不保证精度提高；需要已有结果或明确授权的实验范围。

输入：任务定义、数据来源/划分、模型和导出哈希、预处理/后处理、预算、候选选择规则、冻结阈值/容差、环境/精度、逐样本输出与真值。缺真值只能作诊断或稳定性描述。

输出：候选登记表、数据角色与隔离审计、固定指标/失败门槛、逐样本/分组对照、全部种子统计、采纳/否决和部署边界报告。证据归档模式只读现有记录，不下载数据、不启动训练或推理。

失效条件：测试集参与调参却仍称独立测试；人物/视频泄漏；输出语义或预算不一致；修改容差让失败变通过；仅报最好种子；没有事件真值却报误触发率；服务器/离线结果冒充板测。先标明冲突和不确定性，再决定可独立推进的检查。
