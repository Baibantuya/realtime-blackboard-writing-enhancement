# CDC 与复位的本机增量审查

2026-10-29。只读打开 R5 已布线 DCP，记录到 `structural/`；不修改约束、不新增 false path 或 waiver，不重新生成板端文件。汇总与复查入口为 `review.json`、上级 `audit_cdc.py`。

## 复位组件仿真

使用 R5 由 Vivado 2025.2 生成的 proc_sys_reset 功能网表，在理想 200 MHz 时钟下覆盖：首次释放；20／40／80 周期外部复位与四种切换相位；锁定信号丢失；复位期间停钟、在停钟时释放请求并恢复时钟；先停钟再请求复位。

18 次输出复位事件均满足断言，最短保持 64 个有效上升沿，超过本测试检查的 40 周期下限。停钟时没有提前释放，恢复时钟后在 200 周期界限内释放。见 `simulation/simulate.log`。旧测试的最短 45 周期与这里的 64 周期来自不同刺激，不能据此声称硬件脉宽有所改善。

## 网表结构

- 两条配置字跨域：2 位 active_lanes 对应 6 个同步触发器，16 位 vc_en 对应 48 个；均有 0／1／2 三级，54 个同步触发器均带 ASYNC_REG。它们仍是逐位同步，不能证明配置字原子更新。
- 4 项 LUTAR-1：MIPI 路径为 LUT2、INIT=4'h8，另外三项 AXI downsizer FIFO 路径为 LUT3、INIT=8'hFE。已记录输入起点、扇出端点、触发器属性及接收时钟。MIPI 告警涉及的三级异步复位同步器仍存在。
- `all_fanout` 记录包含 CLR/PRE 以外的端点，不能把扇出数直接叫作异步复位引脚数。部分厂商层级边界的第一级驱动列为空，不等于无驱动或安全证明。
