# 2025.2 源码重建候选

本目录提供与c5通过数值时序检查时一致的HLS算法、RTL、BD、引脚和时钟约束。
不包含生成IP、综合检查点、缓存、位流或厂商工具。原v24未替换。

Windows使用已安装且具备目标器件/IP许可的Vivado与Vitis 2025.2，在短ASCII路径的全新目录解压。
运行 build/run_all.ps1 -ToolRoot <2025.2安装目录> -Python <Python路径>。
脚本自动创建logs/report，顺序执行三核HLS、禁用IP缓存的整机综合、布局布线、复位组件测试和前后源文件校验。
已有h/v/i输出时拒绝重跑，请保留现场并使用新的源码副本。

本机使用的私有UTF-8环境只通过可选参数 -VivadoOverlay <路径> 传入，不包含在此包中；
它是针对特定Windows工具崩溃的实验兼容措施，不是AMD官方补丁。
不应在没有对应崩溃证据的机器上默认需要该措施。Linux入口build/run_all.sh尚未整流程验证。

测试范围：Rectify有20组1080p C测试、无RTL联仿；Scene和Restore使用原有限测试平台，
分别9和123次RTL事务。复位测试限组件，不覆盖相机上电、电气接口和目标Linux驱动。
是否通过必须查看本次实际日志、退出码、i/timing.rpt、CDC/DRC以及板端测试。
运行完成不自动导出位流，不烧写板卡。本阶段无神经网络或手势控制。
