# 可复用提示词草稿

以下改写自 S/skill/06_prompt_workflows 三组主题。是后续任务模板，不是原始 AI 对话，也不意味着已在多个平台执行成功。

**软硬件划分**：请基于给定版本的源码、帧格式、阶段输入输出与实测瓶颈分析划分。列出带宽、存储、时延假设的来源，区分实现与计划。保留并行流水和缓冲所有权，不因单个阶段方便而改成串行单帧。给出最小离线验证及需实机验证部分，未授权时不部署。

**HLS接口核验**：请对照同次构建的HWH、生成头文件和配置，检查实例、基址、范围、寄存器偏移、访问、字段与逐指针位宽。m_axi_addr64按核核对；缺字段或歧义应失败，不能补零。迁移前后分支分别记录，零寄存器元数据写NOT_CHECKED；静态相符不等于时序或板端通过。

**ARM瓶颈审阅**：请先定义事件与测量窗口，分开采集FPS、有效内容更新FPS和呈现FPS。对齐帧身份、单调时间与缓冲拷贝，给出每段耗时和数据量，再选择一个可验证的优化。不得用PC结果估算板端已达标，也不把content_duration写作端到端延迟。阈值未给定时只报告观测值。

每次执行后记录输入指纹、实际操作、原始输出和未验证项。AI_Sessions由独立对话整理，本工作区仅对接案例编号和工程证据路径。
